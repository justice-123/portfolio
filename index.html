01 — Overview

The Premise

Project Asphyxia is a first-person VR horror game built for standalone Meta Quest 3. The central mechanic is simple and deeply unsettling: the monster that hunts you responds to the sound of your breathing — captured live from your headset microphone.

Panic, and your breath betrays you. The game's suspicion system drives post-processing vignette effects that close in as the creature grows more aware. There is no hiding from your own body.

Built by a small team using Unity's XR Interaction Toolkit with OpenXR, the project features an entirely custom machine-learning breath detection pipeline trained on real recorded data.

02 — Core Technology

The Breath Engine

01
Microphone Capture
Quest 3 onboard mic. Continuous streaming audio buffer sampled at runtime inside Unity.
02
RMS Gate
Amplitude range filter. Loud signals (speech, knocks) bypass ML — handled by autocorrelation pitch detection instead.
03
MFCC Extraction
Mel-Frequency Cepstral Coefficients extracted in C#, mirroring the Python training pipeline exactly to prevent feature mismatch.
04
LSTM Inference
4-class LSTM model (inhale / exhale / silence / noise) exported to ONNX, running via Unity Sentis on-device.
05
Suspicion System
Inhale detections above 0.95 confidence threshold drive the monster's suspicion level — feeding post-process vignette FX.

On training / inference parity: a custom mfcc_mirror.py tool was built to exactly replicate the runtime C# MFCC extraction in Python during training. Frame count mismatches (43 vs 47 frames) between librosa defaults and the Unity implementation caused silent accuracy loss — this tool ensures the model sees identical features at runtime. ONNX export uses dynamo=False with no dynamic axes — the settings required for Unity Sentis compatibility.

04 — Tech Stack

Built With

Engine
Unity URP
Universal Render Pipeline. Additive scene loading with persistent CoreScene architecture.
XR
XR Toolkit
XR Interaction Toolkit with OpenXR. NearFarInteractor for grabbing and interaction.
ML Runtime
Unity Sentis
On-device ONNX inference via Unity's Sentis (formerly Barracuda/Inference Engine).
ML Training
PyTorch + ONNX
LSTM trained in Python with librosa for feature extraction, exported to ONNX with dynamo=False.
Platform
Meta Quest 3
Standalone Android build. Developed via Meta Horizon Link PC VR mode.
Input
Input System
Unity Input System with Input Actions assets. Meta Quest Touch controller profile via OpenXR.
Architecture
GameEvents Bus
Static event bus for cross-scene communication. Prefab ownership model for team Git workflow.
Audio
LibriSpeech
Training data includes custom breath recordings + LibriSpeech speech samples for noise class robustness.
